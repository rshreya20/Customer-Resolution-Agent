# Customer-Facing Resolution Agent

A simple, runnable prototype for the airline-disruption assignment.

## What it does

- Uses only the three customers, three bookings, service rules, allowed actions, prohibited actions, and scenarios in the supplied Data Pack.
- Handles:
  - airline cancellation → refund or free next-available rebooking
  - 4-hour delay → meal voucher + lounge access; hotel request is not covered
  - 6-hour delay → meal voucher + hotel for delayed hours only
  - higher-fare rebooking with ₹2,000 fare difference → cannot waive without supervisor approval
  - legal/formal complaint → immediate human escalation
  - unsupported upgrades/additional compensation → human escalation
- Includes a Streamlit customer-facing chat UI.
- Does not require an API key or external database.

## Run locally

Python 3.10+ recommended.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Then:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit.

## Demo

Use the three buttons in the sidebar. They load the exact assignment scenarios.

## Architecture

Customer UI → ResolutionAgent → Knowledge Base / Policy Rules → Resolution + Escalation

The core decisions are deterministic rather than generated by an LLM. This makes the prototype auditable and reduces hallucination risk, which is important because the assignment explicitly says not to invent policies or customer information.
